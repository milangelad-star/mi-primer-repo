# Mantenimiento docente del repositorio público

1. Mantener **el README como puerta de entrada** con enlaces oficiales y verificación de herramientas.
2. Modificar la misión y las dos pistas de la sala afectada de forma coordinada.
3. Verificar que `bash desbloquear.sh N` es reproducible; no añadir claves o contraseñas.
4. Cambios en `scripts/analizar_operaciones.py` requieren comprobar el informe y el notebook.
5. **No publicar soluciones docentes ni evidencias**, aunque el repositorio sea privado: podrían hacerse públicos por error.
6. El material es educativo: se debe preservar el objetivo **encontrar → versionar → documentar → organizar → calcular → explicar**.
