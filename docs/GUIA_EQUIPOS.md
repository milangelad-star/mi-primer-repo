# Cómo abrir una copia local por equipo

Si hay seis ordenadores, repetid la descarga una vez en cada uno. Si varias personas usan el mismo equipo en momentos diferentes, **descomprimid** el ZIP en carpetas separadas:

```text
Documentos/
  roomscape-equipo-01/
  roomscape-equipo-02/
  ...
  roomscape-equipo-06/
```

No se debe compartir la misma carpeta de evidencias entre equipos ni subir un ZIP con las soluciones. No hace falta clonar repositorios para empezar: se recomienda **Code → Download ZIP**, ya que la primera puerta enseña la terminal y la segunda introduce Git desde cero.

La versión publicada del material contiene todas las pistas para aprendizaje autónomo; el comando `desbloquear.sh` valida las evidencias, pero no bloquea físicamente la lectura del siguiente directorio.
