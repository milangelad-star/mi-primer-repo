# Puerta 04 · Visor de Código

**Tiempo de referencia:** 30 min. Cambia de persona al teclado al menos una vez.

## Desafío

Sublime permite editar texto. **VS Code** sirve además para trabajar con una carpeta de proyecto, una terminal y extensiones.

1. Abre **VS Code → Archivo → Abrir carpeta** y selecciona la **raíz del roomscape** (no solo la sala 04).
2. Busca las carpetas `datos/`, `scripts/` y `notebooks/` en el panel Explorador.
3. Abre **Terminal → Nuevo terminal**, identifica si estás en PowerShell o Bash y localiza cómo cambiar de terminal.
4. Abre Extensiones y comprueba **Python**, **Pylance** y posteriormente **Jupyter**.
5. Crea `evidencias/mapa_editor.md`, con cabecera `# Mapa del editor`, una línea con `VS Code`, una línea con `Python`, y explica qué carpeta contiene los datos y cuál contiene el código.
6. Ejecuta en Git Bash `bash desbloquear.sh 4`.

**No es necesario instalar PyCharm.** El objetivo es distinguir editor ligero, IDE especializado y entorno extensible.
