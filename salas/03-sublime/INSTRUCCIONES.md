# Puerta 03 · Pluma Sublime

**Tiempo de referencia:** 15 min. Cambia de persona al teclado al menos una vez.

## Desafío

Un hallazgo que no se documenta se pierde. Abre **Sublime Text** y crea `evidencias/bitacora.md` usando este esquema:

```markdown
# Bitácora de Ciudad Métrica

## Hallazgo
He encontrado ...

## Pregunta
Quiero saber ...
```

Escribe un hallazgo **específico** de las dos primeras salas y una pregunta real de análisis. Guarda el archivo con codificación UTF-8.

Verifica desde Git Bash con `cat evidencias/bitacora.md`. Comprueba la puerta mediante `bash desbloquear.sh 3`.

**Prueba de aprendizaje:** diferencia entre texto plano, Markdown y un fichero con extensión `.md`.
